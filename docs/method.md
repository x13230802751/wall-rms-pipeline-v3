# 方法、接口和与论文的区别

参考 Chen、Li、Hong、Li 的《Exploiting Point Cloud Semantic Segmentation for Automatic Geometric Measurement in Modular Construction》第 2.1、2.2.1、2.2.3 节。原文为用户本地参考材料，没有随仓库重新分发。

| 论文步骤 | 本项目实现 | 区别 |
|---|---|---|
| Point Transformer V3 给点赋语义 | 可选读取外部 NPY 类别；默认使用几何 | 没有训练好的神经网络；几何模式不能保证语义类别 |
| 半径过滤孤立点 | 体素代表点的半径邻居计数 | 用于发现支持面，不直接删除最终测量点 |
| 迭代 RANSAC | 固定随机种子、多候选面、有限迭代 | 参数可审计；迭代上限触发时告警 |
| DBSCAN 保留最大连通块 | cKDTree 半径邻域和核心点连通分量 | 每个候选只保留最大块，其余片段可能丢失 |
| SVD、接地筛选、前四面墙 | 相同基本结构，加方向/尺寸筛选 | 保留全部合格候选，并标记主要四面 |
| 墙面点集 SVD 与 RMS | paper / expanded 两种集合 | 默认 expanded 恢复更多实际墙点，避免直接删掉鼓包 |

这是参考论文的几何流程与语义标签接口，并非完整深度学习结果复现，也非课程双头模型训练成果。

## 自动找墙的规则

1. 明确单位和 up 向量；过滤非有限坐标，保留原始编号。默认 +Z 向上。
2. 体素只选择代表点，不平滑正式测量点；邻居计数清除发现阶段的孤立代表点。
3. RANSAC 在有界样本上评分，在全部当前代表点上评估支持，SVD 细化。
4. 对支持点作 DBSCAN，保留最大连续区域。移除本次平面的代表点后继续搜索。
5. 从接近水平且靠近房间底部的候选中选择支持最多的地面。没有可靠地面即失败。
6. 检查墙方向、宽高、包围面积与最低 1% 支持点到地面的距离；默认接地容差 250 mm。
7. 从二维支持凸包内部，以及支持点附近 100 mm 内恢复原始点，法向限定 ±50 mm。不同墙面与水平面按到平面的距离竞争，减少墙角重复归属。
8. 提供语义标签时，恢复集合还必须属于 wall 类。没有标签时，只提供几何候选，不能推断所有附属物的语义。

凸包跨越开口不意味着造点，只选择输入中实际已有的点。但开口内门框或背景若落入厚度范围，仍可能被包含。超出 50 mm 的大鼓包、严重遮挡和不连通墙片可能漏掉；加大恢复范围会增加污染风险。

## 墙号与测量

墙号按中心全局 XYZ 排序，固定文件/参数/版本下确定，不是跨房间或跨参数的永久身份，也不是官方真值墙号。必须结合位置、法向量、点数和图确认。

`measure` 根据墙号恢复原始点索引。可选四点 JSON 仅在这一面墙的集合内裁剪；四点只服务选区，最终参考面由实际选中点重新拟合。RMS 为点加权的垂直距离均方根。法向量朝向房间中位点只是启发式，不能把正号直接叫鼓包。

## 评价

合成数据提供真实墙身份和几何曲面。独立使用协方差特征向量求面，再由残差求 RMS，验证 SVD 计算。评价点集 precision/recall/IoU，以及最终 RMS 与同场景全部观测真实墙点 RMS 的差异。噪声场景的参考含噪声，不能称为无噪实体真值。

真实数据独立复算证明索引、坐标、距离和数值一致性。官方人工测区和方法未完整核实，因此没有输出“官方真值准确率”。不同墙、不同范围、不同筛选规则的 RMS 不能直接相减当作算法误差。

几何规则能排除部分悬空小板，不能可靠区分贴墙盒子和真实鼓包。测试保留这类失败。外部可靠语义标签、明确测区和人工复核是改善方向。

## Python 接口

```python
from room_walls.config import Config
from room_walls.discovery import discover
from room_walls.measurement import measure_wall

# points_m: N x 3 米单位数组；labels: 可选 N 个整数。
catalog = discover(points_m, Config(), labels=None)
wall = next(w for w in catalog['walls'] if w['id'] == 'W01')
result = measure_wall(points_m, wall, mode='expanded')
print(result['rms_mm'])
```

文件/CLI 层负责单位、哈希、目录保护和可视化。Python 几何接口只接收米单位，不能未经转换传入毫米坐标。
