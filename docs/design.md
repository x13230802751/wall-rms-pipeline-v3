# 整房间墙面识别与 RMS 测量设计

修订日期：2026-11-22。本项目实现墙面候选发现与 RMS 测量。

## 目标与边界

输入整房间点云，自动输出可审查的墙面编号、位置、范围和点索引；用户选择墙号后计算 RMS，可进一步使用四点限定局部区域。本项目以独立仓库交付。这里复现论文的几何后处理思路，不宣称重现其神经网络：本地没有训练标签、模型权重或 GPU 框架。默认 geometry 模式按几何寻找候选墙，semantic 模式接收外部模型输出的逐点类别；两种模式均能运行后续提取和测量。外部类别不是模型训练的替代证据。

## 路线选择

1. 默认几何识别：无需训练，直接在官方点云运行，但柜体、挡板可能被误认，框内杂物也可能污染 RMS。
2. 语义标签 + 论文几何后处理：支持用户/模型提供与原始点对应的类别数组，限制 wall/floor/ceiling 点；标签来源、哈希与模式均记录。
3. 完整训练 Point Transformer V3：需要额外标注、权重与训练条件，不把未完成的训练包装成实现结果。

## 数据流和接口

- `discover --cloud ... --unit m --out ...`：只从几何/标签发现候选平面，不输入四点或人工墙号。显式 up 向量约定重力反向，默认 +Z。输出 catalog.json、assignments.npz、概览图、交互 HTML。
- 基于体素代表点迭代 RANSAC，按半径清理孤立点，DBSCAN 选最大连续面，SVD 优化。识别低处水平地面，再依据方向、跨度、面积和接地程度筛选墙面。候选不足明确告警，几何模式不能证明语义正确。
- 不强制假定只有四面墙：目录保留所有通过筛选的候选，另标出按支持点数排名前四的 dominant 墙，方便复现论文。稳定编号由墙面几何位置排序生成，编号仅对固定文件、配置和软件版本有意义。
- 发现用稀疏代表点，测量回到完整输入点云。保存严格平面内点（paper-like）与恢复测量点集（expanded）的原始索引；恢复集合依据墙面二维支持点凸包内部或支持点近邻、以及较宽厚度选点，保留凹凸，不能声称自动去除所有杂物。凸包内部允许保留离平面较远的真实点，但也可能包括开口内杂物；无观测的位置不造点。
- `measure --catalog ... --wall W01 --out ... [--roi ...]`：核对输入点云哈希、配置和索引，使用选定墙恢复点集（默认）拟合。可选择 paper 模式对照；可选四点 ROI 为进一步取交集，不混入别的墙。输出 RMS、逐点距离、偏差图、平面、覆盖诊断与严格内点对照。
- `run --cloud ... --walls all --out ...`：发现并计算全部候选，用户也可传指定墙号列表。无有效墙时报错，不虚构结果。

## 安全和可追踪性

无平滑、无残差二次剔除以压低报告 RMS；不把 discovery 阈值或 RMS 当成验收公差。无覆盖区域不补点。所有单位显式提供；无效点过滤后保留原始行号。非法 up/参数/标签/ROI、空数据、找不到地面、错误墙号、数据哈希不符等有可理解错误。拒绝覆盖非空输出目录。真实数据、派生点云和依赖不纳入 Git。

## 验证

合成完整房间验证自动墙面发现、每面墙点精确率/召回率、已知粗糙度和独立协方差 RMS。加入不同姿态/单位、噪声、离群点、局部鼓包、非接地板、语义排除杂物；验证选墙、四点交集、数据篡改和 CLI。官方 M04/M26 不使用预设四点定位，记录候选位置和实际 RMS，人工查图。官方 1.0/1.8 mm 不自动绑定墙号，不宣称独立物理精度。
